# One-Sentence Absurd Invention Pitch

Entry for [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) on make.fun.

One sentence pitching a ridiculous invention for a tiny everyday
annoyance: the missing sock. The Sock Reunion Drone patrols the laundry,
finds each lost sock's soulmate hiding in the dryer lint, and parachutes
them back together before anyone notices one is gone. The fix is silly
yet weirdly plausible — a rescue mission for laundry — and the laugh
comes from the invention itself, not from a joke bolted on at the end.

`main.py` writes the pitch to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
